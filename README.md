# PocketSmart AI 🤖💜

## Project Description

PocketSmart AI is a smart budget and recommendation assistant
that uses Artificial Intelligence to provide personalized suggestions
for home decoration, party planning, and jewelry selection.

## Features

- Home Decoration Planner
- Party Planning Assistant
- Jewelry Recommendation Assistant
- Budget-based recommendations
- Gemini AI integration
- Login and Registration
- Recommendation History
- Recommendation Details
- Outfit Image Upload for Jewelry Planning

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- Python
- FastAPI
- Jinja2
- Google Gemini AI
- Uvicorn

## Modules

### 1. Home Planner
Provides budget-based suggestions for room decoration,
lights, fans, tables, and other decoration items.

### 2. Party Planner
Provides suggestions for catering, decoration,
and entertainment based on budget and guest count.

### 3. Jewelry Planner
Provides jewelry suggestions based on budget,
occasion, style, and outfit image.
